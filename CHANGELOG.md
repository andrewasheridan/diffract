# Changelog

All notable changes to this project will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
New entries are generated by [Commitizen](https://commitizen-tools.github.io/commitizen/)
from conventional commits when a release is bumped.

## v3.1.0 (2026-11-10)

### Feat

- compare signatures, class bases and class members (#97)

## v3.0.0 (2026-11-10)

### BREAKING CHANGE

- the commit-msg hook and --validate-msg-file now block
types other than feat, fix and refactor, and messages with no type. The
mismatch output shows "possible:" in place of "detected:".

### Feat

- block commit messages whose type is not possible for the change (#95)

## v2.0.0 (2026-11-10)

### BREAKING CHANGE

- The CommitType members fix and refactor are replaced by
code, test and other. The JSON key commit_type is replaced by group and
possible_types. The has_python_changes and has_python_changes_index
functions in git_utils are replaced by get_changed_paths,
get_changed_paths_index and a new has_python_changes that reads a list of
paths.

### Feat

- replace the fix and refactor results with groups of possible types (#93)
